PII Redaction API

Three DeBERTa-v3 models (base, small, xsmall) fine-tuned on 27 PII entity types, served as a FastAPI service on AWS ECS Fargate with a custom domain, Cloudflare TLS, and a GitHub Actions pipeline that lints, type-checks, tests, builds and deploys every push.

0.9557
Macro F1 · base
DeBERTa-v3FastAPIDockerECS FargateCloudflareGitHub Actions
  • Custom WeightedTokenClassificationTrainer with class-balanced cross-entropy for severe O-token imbalance; two-phase training (frozen backbone → full fine-tune) in bf16.
  • Overlapping token chunking with sentence-aware boundary alignment and max-confidence overlap resolution, exposed through both a CLI and Pydantic-typed endpoints.
  • API-key-authenticated endpoint plus a rate-limited public demo, with secrets in SSM Parameter Store.
  • All three checkpoints published to the Hugging Face Hub with model cards covering per-entity F1, GPU latency and distribution-shift behavior.

Gravitational Lens Finding

Binary lens detection under 16.6:1 class imbalance with ConvNeXt-Tiny, within 0.006 AUROC of a purpose-built equivariant network (Parul et al., NeurIPS ML4PS 2024), using a general backbone and careful imbalance handling instead.

0.9887
AUROC · binary

  • 0.98 macro AUROC on 3-class lensing substructure classification via two-phase EfficientNet-B0 fine-tuning with discriminative learning rates.
  • Imbalance handled with WeightedRandomSampler and calibrated BCEWithLogitsLoss pos-weighting.

Flower Classification API

A PyTorch Lightning pipeline across 11 backbones, 71 runs tracked in MLflow, and the project where I found a data-leakage bug that had silently inflated every run’s validation and test accuracy to ~1.0.

0.9837
Accuracy · ViT-B/16
LightningMLflowFastAPIHF HubPyright
  • Fixed the leak, re-evaluated both published models on genuinely held-out data, and added a regression test so it can’t come back.
  • ViT-B/16 reached 0.9837 accuracy / 0.9722 macro-F1; ConvNeXt-Tiny (0.9821 / 0.9694, a third of the weights) is the serving default.
  • Restructured into a v2 FastAPI service (core/routers/utils, AppState singleton, Hub weight loading) with CI: Ruff → Pyright → Pytest → Docker build.
